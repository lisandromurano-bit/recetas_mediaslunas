# Guía Interactiva de Recetas de Medialunas

Bienvenido al repositorio del proyecto. Este espacio contiene documentación técnica y detallada para la elaboración de medialunas de manteca y de grasa.

## Objetivo
Proporcionar un manual paso a paso, preciso y reproducible para la preparación e integración de técnicas de hojaldre en panadería.

## Estado del Proyecto
 **En desarrollo (Estructura inicial)**

## Estructura del Repositorio
* `recetas/`: Contiene las guías específicas por tipo de masa.
* `CASO-DE-ESTUDIO.md`: Documentación sobre decisiones del proyecto y aprendizajes.
